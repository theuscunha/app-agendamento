# App Agendamento

Atendente virtual de agendamento para pequeno negócio.

O cliente final conversa com o chatbot pelo chat para ver os horários livres e marcar um atendimento, com respostas curtas e diretas, como numa conversa de WhatsApp.

## Stack

- Backend: Supabase
- IA: Groq
- Interface: HTML, CSS e JavaScript puro
- Publicação: Cloudflare Pages
